Cette image montre une interface mobile d’un formulaire de saisie dans une application Android. On y voit un écran intitulé “Navigation” contenant plusieurs champs d’entrée utilisateur : nom complet, adresse email, numéro de téléphone et adresse. Un menu déroulant permet également de sélectionner la ville (ici Marrakech). Le bouton “Envoyer” permet de soumettre les informations saisies. L’interface adopte un design simple et épuré, avec des champs bien alignés et une navigation intuitive, adaptée à une utilisation mobile.

![WhatsApp Image 2026-02-21 at 22 33 45](https://github.com/user-attachments/assets/fba61dbf-08e2-43b6-b6f2-5aaf15e4d46d)


Cette image montre le deuxième écran de l’application mobile, intitulé “Screen2”. Il affiche les informations saisies dans le formulaire précédent : le nom, l’email, le numéro de téléphone, l’adresse et la ville (Marrakech).

Cet écran sert de page de récapitulatif permettant à l’utilisateur de vérifier que les données ont été correctement transmises entre les deux activités. Le design reste simple, clair et organisé, avec un affichage textuel aligné à gauche pour assurer une bonne lisibilité.
